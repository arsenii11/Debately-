# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
credentials, personal data, or exploit details in a public discussion.

Report security issues to `privacy@debately.website` with:

- the affected route or component;
- steps to reproduce the issue;
- its potential impact; and
- a suggested fix, if available.

You should receive an acknowledgement within 72 hours. Please allow reasonable
time for investigation and remediation before public disclosure.

## Scope

The supported version is the code on the default branch. AI output quality,
prompt behavior, and incorrect automated verdicts are not security
vulnerabilities unless they expose data or bypass an authorization boundary.
